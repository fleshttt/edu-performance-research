# EduRisk v0.7 — математическая модель выбора стратегии с учётом устойчивости

## 1. Цель

Разработать и **проверить исследовательское правило** выбора способа прогнозирования риска академических затруднений на основе средней точности и её изменчивости между последовательными периодами проверки. Это не новая доказанная математическая теория, а экспериментальная адаптация известных принципов регуляризованного выбора модели и правила одной стандартной ошибки.

## 2. Формализация

Пусть `i` — вымышленный студент, `t` — наблюдаемый учебный период, `y_{i,t}` — бинарный индикатор неблагоприятной оценки в периоде `t+1`. Исходные признаки берутся только из периодов `s ≤ t`.

Каждый из четырёх кандидатов `m ∈ M` формирует `p_m(x_{i,t})`: фиксированное окно, индивидуально адаптированное окно, равномерный ансамбль, ансамбль с весами по внутренней валидации. Все внутренние модели обучаются на прошлом и проверяются в периодах `j ∈ {6,7,8}`. Тестовый период 9 не участвует в выборе.

Для метода `m` и временной проверки `j` определим:

```
AP_mj = AveragePrecision({(y_i,j, p_m(x_i,j)) : i из проверочной когорты j})
μ_m   = (1/J) * Σ_j AP_mj
s_m   = sqrt( (1/(J-1)) * Σ_j (AP_mj - μ_m)^2 )
SE_m  = s_m / sqrt(J), J=3
```

**Правило v0.7 (штраф за нестабильность):**

```
m*(λ) = argmax_m [ μ_m − λ · SE_m ], λ ∈ {1,2}
```

Два коэффициента `λ=1` и `λ=2` заданы **до внешнего эксперимента**, и каждый рассматривается как отдельный кандидат, а не подбирается по результатам отложенного теста. При равном значении используется меньший Brier на внутренних проверках, затем заранее заданный порядок методов.

**Сравнения:** (a) метод v0.6, максимизирующий объединённый inner-OOF AP; (b) максимизация `μ_m` без штрафа; (c) штрафы `λ=1` и `λ=2`; (d) «одна стандартная ошибка»: выбрать самый простой метод среди тех, у которых `μ_m ≥ max_n μ_n − SE_best`. Порядок упрощения: фиксированное окно → равномерный ансамбль → взвешенный ансамбль → адаптивный выбор. Этот порядок — исследовательское допущение, которое надо проверять отдельно.

## 3. Ключевое ограничение трактовки «неопределённости»

`SE_m` оценивает разброс **качества метода на временных проверках**. Это не энтропия или доверительный интервал *индивидуальной вероятности*, не эпистемическая/алеаторная неопределённость и не корректный статистический стандартный error для независимых наблюдений: временные обучающие выборки нарастающие и зависимые, а `J=3` очень мало.

Поэтому `μ_m − λSE_m` интерпретируется как **эвристический консервативный критерий**, а не гарантированная нижняя доверительная граница.

## 4. Процедура эксперимента

1. Для каждого синтетического `seed` генерируются 90 студентов и 10 семестров. Маски пропусков строятся на неизменной исходной выборке по механизмам «нет», MAR, MNAR и пропущенные смежные периоды. Все стратегии получают одинаковые маски.
2. Рассчитываются три отдельных окна `k ∈ {1,3,5}`. Тренировки: до периода 6, 7, 8; внутренние проверки: периоды 6,7,8. На валидации подбираются параметры адаптивного окна и веса ансамбля; отсутствуют обращения к меткам периода 9.
3. По внутренним проверкам выбираются стратегии всеми политиками; **модели не переобучаются для каждого правила выбора**: используются общие готовые предсказания.
4. Для каждого окна базовая модель переобучается по периодам 4–8 и тестируется на периоде 9. Результаты всех правил сохраняются независимо от знака эффекта.
5. Подсчитываются AP и Brier. Парные разности AP против v0.6-селектора вычисляются на одинаковых `seed`/масках/семействах.
6. Для описания вариативности 5000 раз выполняется бутстрэп по **целым независимым синтетическим генерациям**; это не основание для переносов на реальные популяции.

Зафиксировано: 6 seed, 4 механизма, 2 семейства, 3 окна; итого 48 сравнений и 576 обучений моделей. Новую выборку для будущего подтверждающего эксперимента нельзя выбирать после просмотра этих результатов.

## 5. Исходы и критерии дальнейшего исследования

Первичная мера сравнения — AP; дополнительно Brier и распространённость положительного класса. Нужно отдельно измерить калибровку вероятностей с reliability diagrams/калибровочными кривыми. Brier характеризует прогноз в целом и не равен чистой метрике калибровки.

Считать преимущество новым научным результатом преждевременно: аналогичные консервативные критерии известны, а наблюдаемая разница зависит от симуляции. Для диссертации потребуется объяснить специфическую для учебных данных конструкцию признаков, доказать воспроизводимость, провести сравнение с доступными конкурентами и внешнюю проверку.
