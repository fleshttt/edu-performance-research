# Эксперимент v0.3: влияние длины истории и пропусков данных на прогнозирование

**Научная специальность:** 1.2.1 «Искусственный интеллект и машинное обучение».  
**Тема диссертации:** «Модели и алгоритмы мониторинга и прогнозирования академической успеваемости обучающихся для поддержки принятия решений в образовательном процессе».  
**Статус:** воспроизводимый учебно-исследовательский *синтетический* эксперимент, 2026 г. **Не исследование реальных студентов.**

## Научная постановка

**Вопрос:** как длина доступной истории успеваемости (один, два, три, четыре, пять учебных периодов) влияет на качество прогноза академических затруднений при разной доле отсутствующих измерений?

**Гипотеза H1:** учёт нескольких семестров даёт дополнительную прогностическую информацию по сравнению со срезом одного семестра.  
**Гипотеза H2:** выгода от нескольких семестров может увеличиваться при пропусках измерений, поскольку история содержит дополнительные наблюдения.  
**Гипотеза H3:** оптимальная длина истории зависит от модели, доступности информации и механизма возникновения пропусков.

Проверка этих гипотез в синтетической модели позволяет отладить экспериментальный протокол и наметить гипотезы для реальных данных, но **не подтверждает их применимость к образовательным организациям**.

## Данные и целевой признак

- Синтетический генератор фиксирован (`seed=2026`), содержит **420 вымышленных студентов** и **10 смоделированных семестров** на студента.
- Модель использует 3780 строк с исходным периодом **t = 1,…,9** и меткой из следующего периода `t+1`.
- Цель: бинарное значение `next_term_low_performance`: средняя оценка в семестре `t+1` ниже **3,0** по условной шкале 2–5.
- Доступные признаки текущего периода: средняя оценка, посещаемость, выполненные задания, доля несвоевременных работ, освоенные кредиты и номер семестра.
- Для окна **k** дополнительно вычисляются признаки исключительно из семестров **t, t−1,…,t−(k−1)**: лаги оценок, средние, стандартное отклонение оценок, линейный наклон трендов, изменения между t и t−1, число наблюдений и доля отсутствующих периодов.
- Признаки вычисляются с помощью **точного соединения по идентификатору студента и индексу семестра**: отсутствие семестра t−1 не превращает t−2 в «прошлый семестр».

## Схема эксперимента

| Элемент | Выбранный вариант |
|---|---|
| Длина окна | 1 (контрольный срез), 2, 3, 4, 5 семестров |
| Пропуски | 0%, 10%, 25%, 40% |
| Механизм A | MCAR: случайно удаляются отдельные значения измерений |
| Механизм B | Искусственная потеря целого семестра наблюдений: все показатели строки отсутствуют, ключ и метка сохраняются |
| Повторения | Для ненулевых долей пропусков три независимые маски с seed 7, 21, 42; без пропусков — одна контрольная конфигурация |
| Модели | Логистическая регрессия; случайный лес |
| Train | Семестры t=5, 6, 7 (1260 строк) |
| Validation | t=8 (420 строк), используется для выбора длины окна |
| Test | t=9 (420 строк), **не** используется для выбора окна |
| Метрики | Average Precision (основная); ROC-AUC; Brier score (меньше — лучше) |
| Подготовка | Медианная импутация и стандартизация; параметры оцениваются только по train |
| Число обучений | 190 |

**Важно:** пропуск исходных оценок не удаляет целевые метки, полученные из полного набора до искусственного маскирования. Это имитирует оценку качества при частичной наблюдаемости предикторов, но не невозможность получить правильные исходы. Все условия сопоставляются на тех же 420 тестовых студентах.

Две случайные маски A и B дают две идеализированные схемы отсутствия информации. Реальная неполнота обычно носит условный или неслучайный характер (MAR/MNAR). Эксперимент этого не моделирует; результаты нельзя переносить на такие случаи напрямую.

## Алгоритм воспроизведения

```powershell
$env:PYTHONPATH = "src"
python -m edurisk.generate_data --out data/synthetic_long_10_terms.csv --terms 10 --students 420 --seed 2026
python -m edurisk.ablation --input data/synthetic_long_10_terms.csv --output reports
pytest -q
```

Файлы результатов: `reports/ablation_runs_synthetic.csv` — все 190 запусков; `reports/ablation_aggregates_synthetic.csv` — средние и стандартные отклонения между масками; `reports/ablation_selections_synthetic.csv` — выбор лучшего окна **по валидации**; `reports/ablation_summary_synthetic.json` — структура и ограничения эксперимента.

## Меры достоверности и ограничения

1. Выбор окна выполняется только по среднему AP на validation (при равенстве — по лучшему Brier); метрики test показываются отдельно.
2. Эксперимент оценивает прогноз **для тех же вымышленных обучающихся в более поздних семестрах**; перенос на новых студентов и новые образовательные программы не проверялся.
3. Различия между тремя масками **не являются доверительными интервалами обобщения**: они описывают только чувствительность к рандомизации пропусков одной синтетической когорты.
4. Данные сгенерированы простым статистическим механизмом. Настройки генератора предопределяют закономерности в истории, так что результаты не доказывают существования этих закономерностей на практике.
5. Экспериментальные признаки применимы **при условии, что текущий семестр уже завершён**; прогноз относится к следующему семестру. Для раннего прогноза внутри семестра потребуется другое определение момента доступности данных.
6. Показатели качества не должны использоваться как основание для санкций или автоматических решений в отношении студентов.

## Переход к собственному алгоритму

**Кандидат на дальнейшую разработку (не заявленная научная новизна):** адаптивный выбор длины истории с учётом объёма наблюдений, качества данных и устойчивости тренда. Сначала нужно выполнить поиск аналогичных методов в литературе; затем сформулировать точное правило оптимизации, реализовать алгоритм, оценить на независимых временных и межкогортных выборках, проверить калибровку, устойчивость и интерпретируемость.

Возможная постановка: выбирать `k ∈ {1,…,5}` на основании **доступных на момент прогноза** статистик пропусков и вариабельности истории, сравнивая с фиксированными окнами и простым использованием всех наблюдений. Выбор нельзя основывать на неизвестном целевом значении конкретного студента.
