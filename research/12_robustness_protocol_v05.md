# Протокол v0.5: проверка переноса на последующие периоды и новые синтетические когорты

**Диссертация (1.2.1):** «Модели и алгоритмы мониторинга и прогнозирования академической успеваемости обучающихся для поддержки принятия решений в образовательном процессе».

**Назначение:** контролируемое исследование устойчивости ранее предложенного алгоритма адаптивного выбора длины истории. Материал создан для предварительной экспериментальной работы, а не для принятия решений об обучающихся. Все данные полностью синтетические.

## 1. Формальная постановка

Пусть \(i\) — обучающийся, \(t\) — индекс семестра, \(\mathbf{x}_{i,t}\) — наблюдаемые учебные показатели: средняя оценка, посещаемость, доля выполненных заданий, доля освоенных кредитов и доля просроченных заданий. Целевая переменная:

\[
 y_{i,t}=\mathbb{1}\{\mathrm{grade}_{i,t+1}<3.0\}.
\]

Задача — оценить \(p_{i,t}=P(y_{i,t}=1\mid \mathcal{H}_{i,t})\), используя **только известную историю** \(\mathcal{H}_{i,t}=\{\mathbf{x}_{i,s}:s\le t\}\). Из будущего семестра извлекается только контрольная метка для вычисления метрики; она не используется при подготовке признаков.

Для каждого \(k\in\mathcal{K}=\{1,2,3,4,5\}\) строится собственный вектор признаков \(\boldsymbol\phi_k(\mathcal{H}_{i,t})\) и отдельный предиктор \(f_{k,\theta}\):

\[
 p_{i,t}^{(k)}=f_{k,\theta}\bigl(\boldsymbol\phi_k(\mathcal{H}_{i,t})\bigr).
\]

Все обучаемые параметры \(\theta\), медианы импутации и параметры масштабирования оцениваются только на **обучающей части** каждого разбиения. При построении лага \(t-j\) выполняется точное соединение по идентификатору и номеру семестра. Пропущенный семестр не трактуется как предыдущий доступный.

## 2. Конкурирующие правила объединения предсказаний

**Одно фиксированное окно.** На валидации выбирается \(k^*=\arg\max_k \operatorname{AP}_{val}(p^{(k)})\). При равном AP выбирается меньший Brier, затем минимальное \(k\). На тесте используется только \(p^{(k^*)}\).

**Адаптивный выбор v0.4.** Для каждого студента независимо выбирается \(k^*_{i,t}\) из показателей доступных оценок, их полноты и вариативности:

\[
 Q_{i,t}(k)=\ln(1+n_{i,t,k})+\alpha c_{i,t,k}-\beta v_{i,t,k}-\gamma\frac{k-1}{4},
 \quad k^*_{i,t}=\arg\max_k Q_{i,t}(k).
\]

Тройка \((\alpha,\beta,\gamma)\) выбирается по AP **валидации** из 12 заранее заданных вариантов. На тесте применяются зафиксированные значения и правило выбора; метки теста при выборе не используются.

**Равномерный ансамбль:**

\[
 \widehat p^{unif}_{i,t}=\frac{1}{|\mathcal K|}\sum_{k\in\mathcal K}p^{(k)}_{i,t}.
\]

**Взвешенный ансамбль:** для каждого окна из оценки AP на валидации определяется вес

\[
 w_k=\frac{\exp((AP^{val}_k-\max_j AP^{val}_j)/T)}{\sum_{j\in\mathcal K}\exp((AP^{val}_j-\max_l AP^{val}_l)/T)},\quad T=0.05,
\]

и вычисляется \(\widehat p^{weighted}_{i,t}=\sum_k w_k p^{(k)}_{i,t}\). Температура \(T\) фиксируется **до анализа результатов** и не выбирается по тестовой выборке. В качестве контрольных методов также рассматриваются окна \(k=1\) и \(k=5\).

## 3. Разбиения

1. **Legacy anchor:** исходный синтетический набор v0.4 (`data/synthetic_long_10_terms.csv`); обучение t=5,6,7; валидация t=8; тест t=9. Этот сценарий воспроизводит исходные результаты без пропусков на тех же данных и тех же моделях. Пропуски v0.4, отличные от нуля, в этом этапе не повторяются в точности.
2. **Temporal forward:** новый синтетический набор из 300 студентов (13 сгенерированных семестров, с метками до t=12). Три сдвига: (5–7,8,9), (6–8,9,10), (7–9,10,11). В каждой тройке указан интервал обучения, семестр валидации и семестр теста. Одни и те же студенты повторяются между сдвигами: три оценки нельзя интерпретировать как независимые испытания.
3. **Cohort holdout:** четыре непересекающиеся синтетические группы A–D по 120 студентов, созданные с разными seed одного и того же генератора. Разбиения: train A+B, val C, test D и train B+C, val D, test A. Обучение производится на t=5–7, валидация — t=8, тест — t=9. История валидационных/тестовых студентов доступна для расчёта признаков, но ни один из этих студентов не входит в обучение модели.

**Общий запрет:** выбор окна, параметров алгоритма, весов или семейства модели на основе отложенного теста не допускается. В данном эксперименте семейство модели не выбирается — логистическая регрессия и случайный лес рассматриваются раздельно.

## 4. Механизмы искусственных пропусков

\(M_{i,t,j}=1\) означает, что значение j-го признака за семестр отсутствует у модели. Целевой признак, ID студента и номер семестра никогда не маскируются.

- **Контроль:** нет пропусков.
- **MAR по известной посещаемости:** \(P(M_{j}=1\mid\mathrm{attendance}_{i,t})\) растёт при низкой посещаемости. Посещаемость гарантированно наблюдается, остальные четыре числовых поля могут быть скрыты. Нормировка вероятностей задаёт около 25% пропущенных ячеек в общей таблице.
- **MNAR по скрываемому значению:** для каждой переменной относительная вероятность её исчезновения зависит от её истинного значения до маскировки. Симулятор имеет доступ к истинным значениям, модель — нет. Такой механизм нельзя установить по реальным наблюдаемым данным без дополнительных предположений.
- **Блочные пропуски:** у каждого студента скрывается один случайный непрерывный интервал учебных периодов, примерно четверть доступной истории. Этот сценарий **не** именуется MAR или MNAR.

Все модели и методы при одном разбиении получают **одинаковую маску**. Случайный seed фиксирован: 7. Доли пропусков фактически отличаются из-за структуры сценариев и конечности выборки; они сохраняются в `reports/robustness_missingness_synthetic.csv`.

## 5. Основные метрики, критерии проверки и интерпретация

Основная метрика — **Average Precision (AP)**. Дополнительно: ROC-AUC (способность ранжировать положительные случаи) и Brier (качество вероятностных оценок). Основной сравниваемый эффект:

\[
 \Delta AP_{m,s,f}= AP_{m,s,f}^{test}-AP_{fixed,s,f}^{test},
\]

где m — метод, s — сценарий разбиения/пропусков, f — семейство модели. Средняя \(\Delta AP\) по разбиениям используется **только как описательная статистика**, без вывода о статистической значимости. Отрицательные значения включаются в отчёт наравне с положительными.

### Проверяемые ограничения реализации

- Признаки любого периода \(t\) не изменяются при модификации данных \(t+1\) и позже.
- Изменение **только тестовых меток** не изменяет настройки, выбранные на валидации.
- В протоколе новых когорт нет пересечений ID студентов между train, val, test.
- Маскирование не меняет метки/ID/номера семестров.
- Для всех методов внутри сценария используются те же train/val/test и те же маски пропусков.
- API возвращает только результаты синтетических экспериментов.

## 6. Ограничения и научное продолжение

Полученные числа нельзя считать оценкой реальной эффективности в ТУСУР, другой организации или при ином механизме пропусков. Нет повторных экспериментов с несколькими seed на каждом сценарии, интервальной оценки неопределённости или проверки на реальных обезличенных данных. Независимость в разделе про когорты означает лишь **разные синтетические ID и последовательности RNG**, а не перенос на неизвестное распределение данных.

Следующий шаг — провести повторные независимые генерации с различными наборами параметров (distribution shift), вложенный подбор методов на train/validation без просмотра тестов, оценку изменчивости эффекта между группами и временными периодами. Согласовать с научным руководителем экспериментальный план и условия этичной работы с обезличенной академической статистикой.
