# Данные

`synthetic_demo.csv`: только синтетический демонстрационный набор, создаётся командой `python -m edurisk.generate_data`.

**Не сохраняйте в этом проекте реальные ведомости и идентифицируемые записи студентов.** При наличии согласованного источника реальных данных потребуется отдельная закрытая среда, правила обработки и безопасности, новая схема эксперимента и проверка корректности определения целевой метки.
