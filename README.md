## Постановка демонстрационной ML-задачи

На конец учебного периода `t` известно только то, что имело место не позднее `t`. Нужно спрогнозировать, станет ли средняя оценка студента в следующем периоде `t+1` **ниже 3,0** по принятой **для демонстрации** шкале 2–5.

**Признаки среза:** посещаемость, выполнение заданий, просрочки, текущая средняя оценка, закрытие кредитов, номер периода. **Исторические признаки:** лаги оценок, скользящее среднее, разброс, наклон тренда и изменения других показателей. `student_id` не используется как признак. Целевая метка `next_term_low_performance` не может попадать в матрицу признаков.

**Важно:** порог 3,0, временные периоды и индикаторы — исследовательские допущения для старта, а не утверждённая методика ТУСУР. Их необходимо уточнить с научным руководителем, а затем проверить на подходящих обезличенных данных.

## Интерпретация результатов

- `reports/summary.json` — метрики каждого алгоритма на валидационном и тестовом периодах, способ выбора модели.
- `reports/predictions_synthetic.csv` — демонстрационные вероятности только для пятого периода.
- `reports/selected_model_synthetic.joblib` — обученная на синтетическом наборе модель, **не для промышленного использования**.
- **AP** при редком положительном классе информативнее одной accuracy; нужно анализировать рядом с базовой долей риска.
- **Brier** отражает качество вероятностного прогноза; качество калибровки следует отдельно исследовать на реальных данных.
- Зависимость признаков от результата **не доказывает причинности**.

### Новые API (только локальная синтетическая демонстрация)

- `GET /api/term-trends` — средняя оценка и посещаемость по семестрам.

### Ограничения текущей версии

1. Показатели генератора вымышленные; точность на синтетике ничего не говорит о качестве прогноза в вузе.
2. Одни и те же синтетические студенты встречаются в разных периодах: это проверка прогноза для продолжающих учиться, **не** переноса на новых студентов.

4. Нет допустимого источника реальных образовательных данных и официально согласованного определения риска.
